# Enterprise AI Knowledge Assistant
A professional platform for searching through Machine Learning books using AI (RAG - Retrieval Augmented Generation).

## 🚀 Features
- **Smart Search**: Ask questions about ML books and get accurate answers.
- **Multiple AI Models**: Switch between **Gemini**, **Claude**, and **OpenAI**.
- **Source Citations**: See exactly where the information came from.
- **Knowledge Library**: Browse all indexed ML books.
- **Infrastructure Dashboard**: Monitor system health and performance.

## 🛠️ How to Use
1. **Chat**: Select your preferred AI model (Gemini, Claude, or OpenAI) from the top bar.
2. **Ask**: Type a question like *"How does gradient descent work?"* or *"Explain neural networks"* in the search box.
3. **Explore**: Go to the **Knowledge Library** tab to see all the books currently in the system.
4. **Metrics**: Check the **Infrastructure** tab to see real-time system stats.

## ⚙️ Setup
This app uses:
- **Frontend**: React + Tailwind CSS + Lucide Icons.
- **Backend**: Node.js + Express.
- **AI**: Gemini Pro (via @google/genai SDK).
- **RAG**: Automated context retrieval from a curated ML knowledge base.
